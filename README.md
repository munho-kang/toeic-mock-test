# toeic-mock-test

**종이로 뽑아 실제 시험처럼 푸는 토익(TOEIC Listening & Reading) 모의고사**를 만드는 [Claude Code](https://claude.com/claude-code) 스킬이에요.

"토익 모의고사를 만들어줘"라고 말하면 Claude가 한 회분(200문항)을 새로 만들어요. 문제지, OMR 답안지, 해설지 PDF와 듣기 MP3까지 한 번에 나와요.

## 특징

- **최신 기출 경향 반영**: 만들 때마다 한국토익위원회가 공개한 최신 실제기출 해설 영상의 자막을 받아 읽어요. 강사들이 문제마다 설명하는 함정과 출제 방식을 참고해요.
- **기출을 베끼지 않음**: 기출 문장, 지문, 이름, 숫자는 가져오지 않아요. 문제를 내는 **방식**만 따라 해요.
- **실제 시험지 양식**: 파트 구성, 문항 번호, 지시문, 2단 배치가 실제 시험과 같아요. Part 3·4는 문제마다 가로선으로 구분돼요.
- **듣기 음원**: 미국·영국·호주 억양 음성으로 읽고, 실제 시험처럼 답을 고를 시간을 둬요. 전체 약 45분이에요.
- **자동 점검**: 정답 번호가 한쪽에 몰렸는지, 계산 문제가 너무 많은지, 지문 길이가 다양한지를 빌드할 때 알려 줘요.
- **경향 기록이 쌓임**: 새 회차의 기출 해설을 읽을 때마다 `references/trap-patterns.md`에 새로 알게 된 점을 추가해요.

## 결과물

```
toeic-mock/

│   ├── 3_정답_스크립트_해설.pdf     # 정답, 듣기 대본, 한국어 해설, 예상 점수표
│   ├── 듣기음원/
│   │   ├── LC_전체.mp3            # 이 파일 하나만 틀면 실제 시험처럼 진행돼요
│   │   └── Part1~4 파트별 MP3
│   └── .source/                   # 다시 고칠 때 쓰는 원본 데이터
└── 2회/                           # 새로 만들 때마다 회차 폴더가 하나씩 늘어나요
```

## 필요한 것

이 스킬은 **macOS**에서 동작해요. 음성은 macOS에 들어 있는 `say` 명령으로 만들어요.

| 프로그램 | 용도 | 설치 방법 |
|---|---|---|
| Claude Code | 스킬 실행 | https://claude.com/claude-code |
| Node.js | 시험지 화면(HTML) 만들기 | `brew install node` |
| Google Chrome | HTML을 PDF로 저장 | 앱 설치 (`/Applications`에 있어야 해요) |
| ffmpeg | 음성을 MP3로 변환 | `brew install ffmpeg` |
| poppler | PDF 쪽수 확인 | `brew install poppler` |
| Python 3 | 자막 받기 | macOS 기본 포함 |

자막을 받는 도구(yt-dlp)는 처음 실행할 때 `~/.cache/toeic-mock-test/` 안에 자동으로 설치돼요.

## 설치

이 폴더를 Claude Code의 스킬 폴더에 복사하면 돼요. 아래 명령을 터미널에 붙여넣으면 됩니다.

```bash
git clone <이 저장소 주소>
cp -R <저장소 폴더>/toeic-mock-test ~/.claude/skills/
```

Claude Code를 다시 열면 스킬 목록에 `toeic-mock-test`가 보여요.

## 사용법

Claude Code에서 이렇게 말하면 돼요.

- `토익 모의고사를 만들어줘.`
- `기본 난이도로 만들어줘.`

기존 모의고사가 없으면 1회부터 만들고, 이미 있으면 다음 회차로 이어서 만들어요. 난이도를 말하지 않으면 **고난도**로 만들어요. 한 회분을 만드는 데 자막 읽기, 문제 작성, 음성 합성까지 시간이 꽤 걸려요.

## 폴더 구조

```
toeic-mock-test/
├── SKILL.md                       # Claude가 따르는 작업 순서
├── references/
│   ├── data-format.md             # 문제 데이터(data.js) 형식과 실제 시험 구성표
│   └── trap-patterns.md           # 기출 해설에서 확인한 출제 방식 (회차마다 추가됨)
└── scripts/
    ├── fetch_explanations.py      # 최신 기출 해설 영상 목록 찾기 + 한국어 자막 받기
    ├── gen.js                     # data.js → 문제지·답안지·해설지 HTML + 음성 대본
    ├── audio.py                   # 음성 대본 → MP3 (macOS say + ffmpeg)
    └── build.sh                   # 위 과정을 한 번에 실행하고 결과 폴더에 정리
```

스크립트만 직접 쓸 수도 있어요. 예를 들어 data.js가 있는 폴더에서 시험지를 다시 만들려면 이렇게 하면 돼요.

```bash
# 작업폴더/data.js를 읽어 결과 폴더에 PDF 3개와 MP3를 만들어요
scripts/build.sh <작업폴더> <결과폴더>
# 듣기 내용을 바꾸지 않았으면 음성 합성을 건너뛰어요
scripts/build.sh <작업폴더> <결과폴더> --no-audio
```

## 결과가 저장되는 곳

Claude Code를 연 폴더(현재 작업 폴더) 안의 `toeic-mock` 폴더에 `1회`, `2회`처럼 회차별 폴더로 저장돼요. 이전 회차는 지워지지 않아요. 다른 곳에 저장하고 싶으면 "바탕화면에 만들어줘"처럼 말하면 돼요.

## 저작권 안내

- 이 스킬로 만든 문항은 연습용으로 새로 만든 것이며, ETS 공식 시험이 아니에요.
- TOEIC®은 ETS의 등록 상표예요. 기출 문항과 해설 영상의 저작권은 ETS와 한국토익위원회에 있어요.
- 이 저장소에는 기출 문항이나 자막이 들어 있지 않아요. 자막은 실행할 때 각자의 컴퓨터로 받아 개인 학습용 참고 자료로만 써요.
- `trap-patterns.md`에는 강사 해설에서 정리한 출제 방식(함정의 원리)만 적혀 있어요.
